# Selected Work: Data Science, NLP & Academic Communication

Gutemberg Rapôso

Three focused portfolio pieces connecting Python, linguistic analysis, and clear academic communication. Each study distinguishes what is implemented or demonstrated from what still needs validation.

## 1. English Text Readability

[Read the case study](01_data_science.md)

An interpretable Python prototype that analyzes eight English excerpts with readability metrics and lexical statistics. The case study explains reusable scikit-learn-style components, saved results, preprocessing decisions, and the limits of automated reading-level claims.

**Evidence:** source notebook and stored outputs. No fresh execution, predictive evaluation, or learner-outcome study is claimed.

## 2. Tino: Context-Aware NLP

[Read the case study](02_tino_nlp.md)

An LLM-backed prototype for register-sensitive English feedback, connecting sociolinguistic framing with a FastAPI backend and bilingual interface. The study covers the implemented workflow, source-level engineering choices, and a concrete evaluation roadmap.

**Evidence:** pinned public source files. No live model validation, benchmark accuracy, production scale, or educational efficacy is claimed.

## 3. Academic Editing & Portuguese-to-English Translation

[Read the sample](03_academic_editing_pt_en.md)

A before-and-after academic editing exercise, six explained editorial decisions, and a Portuguese-to-English translation with terminology and claim-strength notes.
